API

This API exposes all recipes, authors, categories, and cuisines in a fully static JSON format for developers, apps, or researchers to explore and use.

Quick Start

  • Fetch all recipes: GET /api/recipes.json
    Returns full recipe data.
  • Search / minimal info: GET /api/search.json
    Returns minimal recipe info for search or listings, including name, author, category, cuisine, and url slug.
  • Filter by category: GET /api/categories/:slug.json
    Example: /api/categories/salad.json returns all recipes in the Salad category.
  • Filter by cuisine: GET /api/cuisines/:slug.json
    Example: /api/cuisines/american.json returns all recipes with American cuisine.
  • Filter by author: GET /api/authors/:slug.json
    Example: /api/authors/meghan-brand.json returns all recipes authored by Meghan Brand.
  • Get API stats: GET /api/stats.json
    Returns total counts for recipes, authors, categories, and cuisines.

Example Workflow (JS)

<script>
fetch('{{ "/api/search.json" | relative_url }}')
  .then(res => res.json())
  .then(recipes => {
    const container = document.querySelector('#recipe-list');
    recipes.forEach(r => {
      const html = `
        <a href="\${'{{ r.url }}' | relative_url}" class="block">
          <div class="flex items-center gap-2">
            <span class="h-px w-8 bg-stone-900"></span>
            <span class="text-[10px] font-bold uppercase tracking-widest">View Ledger Entry</span>
          </div>
        </a>
      `;
      container.insertAdjacentHTML('beforeend', html);
    });
  });
</script>
